# 이미지 분석 내역 리스트·블록 보기 (2026-10-22)

## 화면 변경

- 기존 리스트를 기본값으로 유지하면서 `리스트로 보기` / `블록으로 보기` 전환을 추가했다.
- 블록은 크게·보통·작게의 세 단계로 조절한다. 긴 요약은 생략하고 이미지, 파일명, 처리 상태, 요청 시간, 사용 여부만 표시한다. 긴 파일명은 말줄임하며 전체 이름은 제목 도움말과 접근성 이름에 유지한다.
- 이미지 영역을 누르거나 키보드로 선택하면 기존 상세 검수를 연다. 처리 중 항목은 검수 진입을 막고 요청 취소를 제공한다. 완료·실패·취소된 항목은 기존 삭제 확인을 거친다.
- 양쪽 보기 모두 기존 `날짜 → 함께 요청한 묶음 → 개별 항목` 계층을 공유한다. 이력 페이지 경계에 걸려도 원래 묶음 건수와 현재 페이지 표시 건수를 유지한다.
- 리스트의 파일명 아래에 각 파일의 요청 시간을 초 단위로 표시한다. 실제 생성/요청 시간을 우선 사용하고, 해당 값이 없을 때만 기존 묶음 식별 정보의 시작 시간을 사용한다. 완료/수정 시간을 요청 시간으로 대체하지 않는다. 자료가 없으면 시간 정보 없음을 표시한다.
- 보기 방식과 블록 크기는 사용자별 브라우저 설정에 저장해 다시 열거나 페이지를 새로고침해도 유지한다. 다른 사용자에게 적용하지 않으며 저장소 사용이 제한되거나 값이 잘못되면 기본 리스트/보통 크기를 사용한다.

## 이미지 및 범위

- 저장된 원본 이미지의 기존 인증된 조회 API만 사용한다. 새 공개 이미지 URL이나 AI 호출은 추가하지 않았다.
- 이미지는 지연 로딩·비동기 디코딩하며, 기존 페이지당 8건 제한을 유지한다. 원본 비율을 유지하고 긴 이미지도 미리보기 안에 들어오게 표시한다.
- 저장된 이미지가 없거나 조회에 실패하면 깨진 이미지 대신 별도 안내를 표시한다.
- 분석 요청, 승인, 거래 등록 규칙과 백엔드·DB 스키마는 변경하지 않았다. 이전 미커밋 작업도 보존했다.

## 검증

- 프런트 빌드 및 단위 테스트 39건 통과.
- 모의 API PC·모바일 검사 26건 통과: 세 가지 크기의 실제 높이 차이, 원본 이미지의 잘림 방지, 라이트/다크 표시, 리스트 요청 시각, 보기 전환 및 새로고침 후 설정 복원, 날짜/묶음/페이지 유지, 키보드 검수 열기, 이미지 없음/조회 실패, 요청 취소와 삭제 확인을 검증했다.
- 앞선 진행률·자동 갱신·배지·6장 요청·83건 분할 검수·입력칸 적용·모달 동작 검사도 함께 실행했다.
- 운영·VM·실제 AI 서버는 사용하지 않았다. 커밋·푸시는 별도 요청 시 진행한다.
