# 이미지 분석 알림 읽음 처리 및 사진첩 보기 (2026-10-22)

## 변경

- 알림 배지는 거래 적용/승인 대기 수와 분리했다. `분석 내용 확인 및 불러오기`에 들어가면 완료된 요청을 읽음 처리하여 배지를 없앤다. 아직 승인하지 않은 거래 후보는 그대로 유지한다.
- 읽음 상태는 사용자 ID별 브라우저 localStorage에 저장한다. 모달 재진입·새로고침에도 유지하며, 다른 브라우저/기기에 동기화하지는 않는다. 저장소가 차단되면 현재 화면의 메모리 상태로 동작한다.
- 다른 페이지의 완료 요청도 요약 API의 ID를 기준으로 읽음 처리한다. 내역 화면을 보고 있는 동안 완료된 요청은 읽음으로 처리하고, 화면 밖에서 새로 완료된 요청은 다시 알린다. ID 최댓값을 기준으로 하지 않아 오래 걸린 이전 요청의 완료도 누락하지 않는다.
- `분석 내역 / 기록 새로고침 / 리스트로 보기 / 블록으로 보기`와 크기 선택을 한 수평 도구 모음으로 배치했다. 좁은 화면에서는 도구 모음만 좌우 스크롤되어 페이지가 가로로 잘리지 않는다.
- 도구 모음의 최소 높이와 스크롤 중 고정 위치를 확보해 모바일에서 버튼이 눌리거나 가려지지 않게 했다. 모바일 모달의 제목·닫기·메뉴도 간결한 배치로 맞췄다.
- 블록 보기는 정사각형 이미지 영역을 사용한다. 요청 원본 전체가 보이도록 비율을 유지하며, 아래에 짧은 분석 결과/분석 중 상태와 요청 시간을 표시한다. 상세 검수·취소·삭제는 기존 동작을 유지한다.
- 날짜와 실제 요청 묶음은 유지하되, 개별 이미지 요청은 같은 날짜의 사진첩 행에 나란히 배치해 빈 공간을 줄였다. 기존 크게/보통/작게 보기와 페이지 이동도 유지한다.

## 검증 범위

- 프런트 단위 테스트 46건 통과: 읽음/미승인 분리, 새 완료 ID 알림, 짧은 사진첩 요약 포함.
- PC·모바일 모의 API 검사 38건 통과: 읽음 유지·새 완료 재알림·계정별 저장 분리, 정사각형 배치·수평 도구 모음의 실제 높이와 클릭 가능 여부, 기존 병렬 요청·검수·취소·삭제·보기 설정 회귀.
- 프런트 빌드 및 변경 파일 공백 검사 통과. PC·모바일 테마별 캡처 확인.
- 백엔드·DB·운영 환경은 변경하지 않았다. VM 배포나 실제 AI 호출은 실행하지 않는다.
