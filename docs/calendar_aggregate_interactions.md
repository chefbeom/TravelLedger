# 사용자 설정 집계: 개별 편집·표시 일치 개선

## 재현한 원인

- 기존 집계 스타일의 `align-self: stretch !important`가 새 카드의 개별 높이보다 우선했다. 한 카드를 160px에서 230px로 키우면 같은 행의 자동 높이 카드도 230px로 늘어났다.
- 과거 컨테이너 단위(`cqi`/`cqw`) 글자 규칙, 후속 고정 글자 규칙, 테마의 색상·`-webkit-text-fill-color`가 겹쳤다. 작은/큰 글자 설정이 금액에만 적용되고, 제목·상세 정보와 실제 글자 채움 색상이 달랐다.
- 상세 정보의 `margin-top: auto`와 기존 잘림·말줄임 규칙으로 금액과 상세 정보 사이에 약 53px의 빈 간격이 생기고 좁은 카드에서는 내용이 잘렸다.
- 집계 영역의 편집 버튼이 절대 위치여서 표시 건수 배지와 겹쳤다. 일반 버튼 테마가 크기 조절 손잡이에 배경색을 넣었고, 카드에는 큰 공통 그림자가 남았다.
- 거래 건수에 집계 결과의 실제 필드 `count`가 아닌 `entryCount`를 사용해 숫자가 빠졌다. 목표 위젯은 ‘기간 표시’ 설정을 렌더링에 반영하지 않았다.

## 수정 기준

- 카드 너비·높이와 글자 크기는 독립적이다. 선택한 카드만 크기를 변경하고, 같은 행의 카드나 집계 영역을 강제로 늘리지 않는다. 반대로 집계 영역 높이만 바꾸어도 카드·글자 크기는 유지한다.
- `calendarWysiwyg.css`에서 카드·개인화 미리보기의 글자 크기와 색상 변수를 공통 관리한다. 작은/기본/큰 제목은 12/14/16px, 금액은 20/24/30px, 상세 정보는 11/12/13px이다. 화면 또는 카드 너비에 따라 저장된 글자 크기를 재계산하지 않는다.
- 민트·하늘·오렌지·핑크는 밝은/어두운 테마별 색상으로 일관되게 표시하며, 제목·금액·기간·상세 정보에 실제 글자 채움 색상까지 반영한다. 그래프의 수입·지출 선 색상은 구분을 위해 유지한다.
- 금액 다음에 기간·거래 건수·수입/지출이 자연스럽게 이어지도록 한다. 긴 제목과 금액·상세 정보는 줄바꿈하며, 직접 지정한 고정 높이보다 내용이 크면 카드 내부 스크롤로 접근한다. 다른 카드의 크기나 저장 좌표를 임의로 변경하지 않는다.
- 그래프 상세 정보도 큰 강제 간격 없이 제목·금액 다음에 표시한다. 그래프 자체는 선택한 카드의 높이에 맞게 커진다.
- 집계 편집 도구는 배지 옆 별도 공간을 사용한다. 조회 중에는 숨기고 비활성화하되 같은 공간을 유지하여 편집/저장 때 카드 위치가 바뀌지 않게 한다. 좁은 화면에서는 영역 설정을 접근 가능한 아이콘 버튼으로 표시한다.
- 카드의 무거운 그림자를 없애고 크기 조절 손잡이는 투명하게 유지한다. 편집창 버튼은 마우스 오버·키보드 포커스에서도 글자 대비를 유지한다. 영역 설정과 ‘선택한 위젯만 변경’을 구분해 안내한다.

## 호환성·범위

- 집계 계산 방식, 거래 저장/공유, 계정별 설정 저장 API와 revision 충돌 처리는 유지한다. 새로운 DB 마이그레이션은 필요 없다.
- 기존 카드 크기·표시 설정은 그대로 읽는다. 저장 전 초안, 취소 복원, 저장 후 새로고침·다른 기기 복원 원칙을 유지한다.
- 사용자가 지정한 영역/카드 크기를 자동으로 압축하거나 다른 카드에 분배하지 않는다. 고정 크기를 유지한 채 생기는 여유 공간과 화면 오류로 발생한 간격을 구분한다.

## 검증

- `frontend/e2e/calendar-aggregate-interaction.spec.js`: PC·모바일에서 개별 크기·글자·네 가지 색상, 표시 옵션, 저장/새로고침, 마우스·터치 드래그, 취소, 영역 높이 변경, 그래프/목표 표시와 긴 제목·큰 금액의 320/390/1024/1440px 줄바꿈을 검증한다.
- 기존 대시보드 편집·개인화·기기 간 복원·달력 툴바·배치 정렬·거래 입력·공유 회귀 테스트를 함께 실행한다.
- 로컬 모의 API 기반 화면 검증이며 VM/운영 배포·검증은 수행하지 않는다.
