# 달력 가계부 개인화 통합 개선 — 2026-10-22

## P0 조사 결과

- `CalendarWorkspace.vue`가 조회·GridStack 배치·집계 폼·입력 설정·표시 설정을 모두 관리한다. 집계 6개에 각각 폼을 넣어 8열 안에서 설정 UI가 축소된다.
- 배치는 `user_layout_settings / household-calendar`, 화면 설정은 같은 테이블의 `household-calendar-view`, 집계는 `app_users.household_aggregate_settings_json`에 저장한다.
- 배치 이동은 즉시 저장하며 표시 옵션은 800ms 뒤 자동 저장한다. 집계는 별도 저장 버튼이며 저장 결과를 기다리지 않고 편집을 닫는다. 통합 취소와 오류 복구가 불가능한 상태다.
- 집계는 합계·결제수단·누적 그래프·월 목표·미사용의 6개 슬롯이다. 기간·기준·목표·그래프 선/비교·축 최대·글자 크기/색·순서·차트 너비를 지원한다. 새로운 무관한 그래프 종류를 만들어 내지 않는다.
- PC의 9열 주 레이아웃과 집계의 8열 내부 그리드, 모바일 별도 흐름이 겹친다. 작은 위젯 내부의 설정 스크롤과 고정 패널 높이가 문제를 키운다.

## 구현 방향

1. 상단 조회 도구는 날짜·보기·표시 필터와 개인화/대시보드 편집으로 정돈한다.
2. 개인화 공통 패널을 대시보드 구성, 달력 표시, 집계 위젯, 거래 입력, 기본값 관리로 나눈다.
3. 집계 카드에서는 결과만 렌더링하고, 선택한 카드 하나의 설정을 공통 편집기에서 수정한다. 이름·숨김·표시 크기를 기존 JSON 저장소에 호환 확장하고 복제·삭제(슬롯 비우기)도 제공한다.
4. 편집은 임시 세션이다. 실시간 미리보기 중 자동 저장을 막고, 저장·취소·미저장 이탈 확인을 통일한다. 저장 실패 시 초안을 유지한다.
5. 기존 저장소를 재사용하는 통합 저장 API로 배치·화면·집계를 하나의 트랜잭션에 저장한다. 사용자 단위 잠금과 상태 revision 검사로 동시 편집 충돌을 탐지한다. 신규 테이블/파괴적 마이그레이션은 만들지 않는다.
6. 사용자 원본 배치를 임의로 바꾸지 않고 좁은 화면에서는 읽기용 반응형 흐름을 사용한다. 집계 결과는 최소 가독 너비를 확보해 줄바꿈하고 설정 폼에는 카드 크기를 적용하지 않는다.
7. 초기화는 배치/표시/위젯 범위를 분리하고 확인한다. 거래 데이터는 대상이 아니다. 사용자 프리셋·되돌리기/다시 실행 등 P6 후속 기능은 핵심 편집 흐름 안정화와 별도로 구분한다.

## 검증 계획

- 기존 설정 호환·사용자 격리·통합 저장 롤백·동시 수정 충돌을 격리 DB에서 확인한다.
- PC·태블릿·모바일에서 공통 편집기, 작은 카드, 저장·취소·오류·초기화·조회/거래 입력 회귀를 모의 API로 검증한다.
- 앞선 이미지 5건 분할 작업은 유지한다. VM/운영 배포 및 커밋·푸시는 별도 요청 없이 진행하지 않는다.

- 위젯 내부의 반복 설정 폼과 개별 저장 버튼을 제거했다. 일반 모드는 결과만 표시하고, 편집 모드에서만 설정 버튼과 드래그 영역을 제공한다.
- 결과 카드는 일반 240px, 결제수단 280px, 그래프 440px의 가독 최소 너비를 기준으로 줄바꿈한다. 화면이 더 좁으면 가용 너비에 맞춘 단일 열이다. 설정 편집기 크기는 카드 크기와 무관하다.
- 기존 9열 영역 좌표와 6개 집계 슬롯은 유지한다. 읽기·화면 회전만으로 좌표를 재정렬하거나 저장하지 않는다. 명시적인 크기/좌표 수정에서 발생한 충돌만 빈 위치로 배치한다.
- 배치 편집 종료 후 GridStack의 인라인 크기가 일반 화면을 축소하지 않도록 분리했다. 달력의 세로 크기는 실제 내용을 기준으로 계산하고 인라인 거래 시트는 달력·입력 영역 아래에 놓인다.
- 저장되지 않은 로컬 배치가 서버보다 새로우면 공통 편집기에서 보관된 배치를 초안으로 유지하고, 서버 설정을 다시 열거나 명시적으로 저장하도록 안내한다.
- 새 테이블·칼럼·Flyway 마이그레이션은 필요하지 않다. 기존 설정을 읽을 때 강제로 추천 배치를 적용하거나 서버에 기본값을 쓰지 않는다.

## 저장·호환성

- `GET/PUT /api/account/preferences/household-personalization`이 기존 세 저장 영역을 묶는다. 저장은 인증된 사용자 기준이며 다른 사용자 식별자를 받지 않는다.
- 사용자 행 잠금과 사용자 ID·설정 내용 기반 revision으로 변경을 확인한다. 다른 창 또는 구버전 설정 API에서 저장한 뒤의 오래된 revision은 409로 거부한다.
- 신규 설정 저장은 하나의 DB 트랜잭션이다. 중간 실패 시 집계와 두 배치/화면 설정 모두 롤백된다. UI는 오류 후 초안을 유지하며 동일 초안으로 재시도할 수 있다.
- 기존 개별 API도 유지한다. 구버전 위젯 PUT에서 누락된 이름·숨김·표시 크기와 구버전 화면 PUT에서 누락된 빠른 입력 표시·기본 보기 값은 기존 값으로 보존한다. 관련 구버전 쓰기도 같은 사용자 잠금을 거친다.
- 저장 전 취소·화면 이동·새로고침 확인을 제공한다. 서버가 저장을 확인한 뒤 로컬 캐시를 갱신하며, 캐시 용량/권한 오류는 서버 저장 성공을 실패로 바꾸지 않는다.
- 집계 기간을 수정하면 필요한 조회 범위를 지연 갱신하고 이전 응답이 최신 응답을 덮어쓰지 않게 한다. 글자/이름 수정에는 추가 저장 요청이 없다.
- 프런트와 백엔드는 함께 배포해야 새 통합 저장 API를 사용할 수 있다. 운영/VM 배포는 이번 작업에서 하지 않았다.

## 후속 수정: 편집 격자와 실제 카드 정렬

- 안내선에 이전 배치 보드의 12px 바깥 여백이 남아 있어 GridStack의 실제 시작 좌표·열 간격과 달랐다. 달력 카드의 자동 높이 강제값도 편집 모드까지 적용되어 카드 테두리가 지정한 칸 높이를 벗어났다.
- 안내선을 실제 GridStack 안으로 옮기고, 안내선의 여백·행 높이·간격이 GridStack의 CSS 변수와 같은 값을 사용하도록 했다. 편집 중에는 카드 테두리를 배치 칸에 맞추고 긴 내용만 카드 안에서 스크롤한다. 일반 화면의 내용 기준 높이와 기존 저장 좌표는 유지한다.
- 수정 전 네 모서리 좌표 비교 테스트에서 최대 약 294px 오차를 재현했다. 수정 후 1024·1440·1920px 및 라이트/다크 테마에서 안내선과 모든 카드 테두리의 오차가 1px 미만임을 검증했다.
- 실제 마우스 드래그·크기 조절, 저장·새로고침 후 좌표 복원, 모바일 전환·PC 복귀, 취소 및 기존 개인화 동작을 검증했다. 관련 브라우저 테스트 31건 통과(PC 전용 정렬 테스트의 모바일 중복 3건은 제외), 단위 테스트 55건·프로덕션 빌드·PWA/mobile baseline도 통과했다. 브라우저 API는 모의 응답이며 VM/운영 배포는 하지 않았다.

## 후속 수정: 빠른 거래 입력 통합과 날짜·시간 수평 배치

- 금액과 나머지 입력 항목을 나누던 두 내부 박스의 배경·테두리·패딩을 제거해 하나의 입력 영역으로 연결했다.
- 날짜와 시간을 같은 줄에 두고 입력란 높이·시작 위치를 맞췄다. 시간 사용 체크는 시간 제목 옆에 두고, 24시간제/미사용 시 00:00 안내는 두 입력란 아래 공통 줄로 옮겼다. 중첩된 label 구조를 제거하고 날짜와 시간 사용 체크에 명시적인 접근성 이름을 지정했다.
- 좁은 카드에서는 날짜 이전/다음 버튼만 날짜 입력란 아래로 옮겨 날짜·시간을 나란히 유지하면서 44px 터치 높이와 입력 공간을 확보했다. 기존 날짜 이동, 금액 바로입력, 원화/외화·수입/지출 전환, 시간 사용 및 저장 처리는 유지한다.
- Chromium PC·모바일의 320·360·390·412·1024·1440·1920px 및 라이트/다크 테마에서 별도 내부 박스가 없는지, 날짜·시간의 수평 정렬·높이·가로 넘침을 검증했다. 실제 저장 요청의 시간 지정값과 미사용 시 00:00도 모의 API로 확인했다.
- 새 입력 회귀 테스트와 기존 개인화·배치 정렬·공유 테스트 69건 통과(PC 전용 배치 테스트의 모바일 중복 3건 제외). 프런트 단위 테스트 55건·프로덕션 빌드·PWA/mobile baseline·변경 파일의 UTF-8 BOM 검사·git diff --check도 통과했다. 백엔드/API/DB 구조 변경과 VM/운영 배포는 없다.

## 후속 범위

- 사용자 지정 레이아웃 프리셋의 생성·저장·전환, 편집 실행 취소/다시 실행은 P6 후속이다.
- 기존에 없던 그래프 종류나 주 시작 요일 변경 UI는 추가하지 않았다. 기존 누적 그래프·월/주 보기·일요일 시작 달력을 유지한다.
- P6 후보 중 위젯 복제, 범위별 초기화, 고급 좌표 편집은 이번 공통 편집기에 포함했다.
- 관련 없는 미추적 파일과 병렬 작업 폴더는 수정하거나 커밋 대상으로 삼지 않았다. 커밋·푸시는 별도 요청이 필요하다.
