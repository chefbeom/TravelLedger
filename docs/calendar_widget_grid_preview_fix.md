# 집계 카드 격자 정렬·실시간 크기 미리보기 보완 (2026-10-25)

## 재현한 결함

- `cardColumns/cardRows`가 있는 카드만 격자 크기를 사용하고 구형 픽셀/자동 크기는 247px, 190px 같은 값을 그대로 렌더링했다. 혼합된 카드의 너비·높이와 다음 카드 시작점이 안내 격자와 달랐다. 1440px 재현에서 최대 64px 어긋났다.
- 포인터 이동 시 DOM의 CSS 변수를 직접 변경한 뒤 Vue의 `directGesture`를 갱신했다. 재렌더링이 같은 변수에 원래 설정을 다시 적용해 손을 놓기 전에는 크기가 바뀌지 않았다. 기존 검증은 주로 포인터를 놓은 후의 크기를 확인해 이 차이를 놓쳤다.
- 가는 배경 선만 표시되어 실제 카드의 8px 간격과 셀 테두리를 비교하기 어려웠다.

## 수정

- 모든 표시 프레임은 집계 내부 9열·8px 간격과 대시보드 행 피치로 계산한다. 구형 픽셀/자동 설정도 화면에서는 가까운 정수 칸으로 스냅하며 원본 저장 값은 보존한다. 새 칸 값이 있으면 해당 축에서 우선한다.
- 실제 집계 너비를 관찰하고 팔레트·화면 너비 변경에 맞춰 프레임을 계산한다. 스크롤바 공간을 고정해 내부 스크롤 유무가 바뀌어도 이웃 카드 크기가 흔들리지 않게 한다.
- 셀 자체의 너비·높이·간격을 가지는 격자 안내를 편집 중에만 표시한다. 줄바꿈과 높이가 다른 카드도 같은 격자에 맞춘다.
- 드래그 크기를 Vue 상태로 렌더링해 포인터를 누른 채 이동할 때마다 실제 카드와 강조 테두리가 즉시 갱신된다. 포인터 옆에 `4열 × 3행`과 적용/취소 안내를 표시한다.
- 놓으면 초안에 반영하고 Escape/포인터 취소 시 원래 프레임으로 돌아간다. 같은 칸 안에서 조금 움직인 제스처는 저장할 변경으로 취급하지 않는다.
- 모바일은 화면 너비와 기존 데스크톱 열 수를 유지하며 높이만 조절한다. 구형 열 값 `0`도 모바일 너비로 추론한 열 수로 덮어쓰지 않는다.
- 글자 크기·색, 이웃 카드 크기, 거래 데이터, 저장 API 및 revision 계약은 유지한다. 읽기·미리보기만으로 서버 쓰기를 하지 않는다. DB 마이그레이션도 없다.

## 검증

- `calendar-widget-live-grid.spec.js`: 구형/신규 혼합 카드 경계와 줄바꿈, 실제 안내 셀 크기, 1440/1024/390/320px 조회/편집 일치, 서버 설정 불변.
- 같은 테스트에서 PC 마우스/모바일 실제 터치 입력을 누른 채 여러 칸을 이동하고 두 프레임 뒤의 실제 크기를 확인한다. 포인터를 놓기 전 미리보기를 확인하는 회귀 검증을 추가했다.
- 포인터 옆 크기 표시, 선택 카드만 변경, Escape/포인터 취소, 같은 칸 안의 작은 이동, 저장·새로고침을 검증한다.
- 기존 집계 표시·개인화·WYSIWYG·기기 간 복원·팔레트 정렬·달력 조회·거래 입력·공유 검증을 병행한다.
- 테스트는 로컬 모의 API를 사용한다. 운영/VM 배포, Tailscale/DB 설정 변경은 포함하지 않는다.
