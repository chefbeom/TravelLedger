# 가계부 분할 결제와 할부 표시

- 할부는 카드 지출에 2~60개월과 무이자·유이자를 표시하는 정보다. 거래 금액을 월별로 나누거나 미래 거래를 자동으로 만들지 않으며 이자 금액을 계산하지도 않는다. 기존 할부 기록의 이자 구분은 미지정으로 유지한다.
- 분할 결제는 원화 지출을 2~10개 결제수단별 거래로 한 번에 저장한다. 입력한 전체 금액과 각 금액의 합이 정확히 같아야 한다. 각 거래에는 같은 묶음 식별자와 순번이 표시되며 카드별로 할부 개월을 정할 수 있다.
- 결제 옵션에서 할부와 분할 결제를 각각 켜거나 함께 사용할 수 있다. 함께 사용하는 경우 할부를 적용할 카드별로 개월과 이자 구분을 입력한다.
- 금액 합계와 결제수단별 통계는 각 수단의 실제 금액만 더한다. 달력·검색의 거래 건수는 수단별 건수다. 수정·삭제·공유·환불·결제 취소는 각 거래에서 개별적으로 수행한다. 분할 묶음 전체를 한 번에 공유하거나 등록 취소하지 않는다.
- 외화 분할 결제와 여행 기록에 직접 연결된 분할 결제는 지원하지 않는다. 여행 계획에 연결한 원화 지출은 가능하다.
- 요청별 식별자와 사용자 단위 잠금으로 동일 요청의 재전송을 중복 저장하지 않는다. 하나라도 유효하지 않으면 전체 요청을 롤백한다. 요청 결과를 받지 못한 경우 같은 입력으로 다시 시도해야 중복 방지 번호가 유지된다.
- 기존 CSV 형식과 공유 스냅샷에는 분할 묶음·할부 메타데이터가 없어 내보내거나 공유된 복사본에 이 표시는 보존되지 않는다. CSV는 수단별 금액을 별도 행으로 내보낸다.
- 스키마 마이그레이션 `V20261030_033_2__ledger_split_installments.sql`이 필요하다. 기존 거래에는 기본적으로 할부·분할 표시가 없다. 배포 전 대상 DB의 Flyway 적용 이력을 확인한다.
- 마지막 수단에는 앞 수단 입력 후 남은 금액을 자동으로 채우며 직접 변경할 수 있다. 총액을 초과하는 금액은 가능한 범위로 조정한다.
- 이자 구분을 저장하려면 `V20261111_059__ledger_installment_interest_type.sql` 마이그레이션도 적용되어야 한다. 적용 전에 대상 DB의 Flyway 이력을 확인한다.
