# 기록 지도: 내 장소와 여행·일정

- 기존 장소 모음을 카테고리 필터로 노출한다. 장소는 여러 모음에 속할 수 있고 기존 모음 공유 링크와 권한은 그대로다. 장소 등록에서 새 카테고리를 추가하면 즉시 저장된다.
- 장소 사진은 날짜 없이도 저장할 수 있다. 내부적으로 날짜가 비어 있는 사진 묶음을 사용하며, 방문 횟수·방문 상태에는 포함하지 않는다. 방문 날짜 필터를 적용하면 날짜 없는 사진 묶음은 해당 결과에 포함되지 않는다.
- 기존과 같이 사진은 방문 기록 공유가 허용된 링크에만 노출한다. 원본 여행 기록을 자동으로 복사하거나 병합하지 않는다.
- 여러 사진의 GPS가 250m 이상 떨어져 있으면 한 장소에 저장하기 전 확인한다. 위치 없는 사진은 비교에서 제외하며 비교를 위해 사진 좌표를 추가로 외부에 전송하지 않는다.
- 여행 생성은 이름·기간을 중심으로 표시하며 목적지·인원·통화 등은 상세 설정에서 변경한다. 생성 후 선택한 여행 지도로 돌아가며 장소·사진과 경로 편집에 진입할 수 있다.
- 장소와 여행 데이터가 서로 다른 원본 모델을 계속 사용하므로 양쪽 지도에 자동 합산되지는 않는다. 기존 여행 장소 가져오기와 원본 수정 경로를 유지한다.
- `V20261111_058__record_map_undated_photos.sql`은 기존 방문 날짜를 변경하지 않고 날짜 열을 nullable로 바꾼다. MariaDB 운영본 적용 전 백업 및 테스트 DB 검증이 필요하다. 날짜 없는 사진이 생성된 뒤 예전 앱으로 되돌리면 예전 앱에서 해당 사진을 표시하지 못할 수 있으므로, 데이터·파일을 보존하고 복구 경로를 먼저 확인한다.
- 지도 목록은 현재 불러온 결과 중 최대 100개를 화면에 표시하며, 기존 서버의 지도 조회 제한은 그대로다. 대량 자료의 지도 범위 기반 조회는 별도 개선 과제다.
